YouTube channels

Configure channels here. They will show in the Upload step.

⚠️ Important — please read before adding a channel:
Adding a channel name + Channel ID here only adds it to the list in the Upload step. It does NOT enable uploading by itself.
Uploading needs the Google sign-in steps below (Client ID + Client Secret saved, libraries installed, python scripts/youtube_connect.py run, token created, then restart run.bat).
If Google sign-in is complete, your channels appear automatically — manual add is not needed.
Upload always goes to the channel of the Google account you signed in with.

  1. Go to Google Cloud Console (console.cloud.google.com), create a project, enable YouTube Data API v3.
  2. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID → Desktop app. Copy the Client ID and Client Secret from there.
  3. Paste them below and press Save YouTube credentials. They are saved only on this computer, in client_secrets.json (never uploaded to GitHub).
  4. Run: pip install google-api-python-client google-auth-oauthlib, then python scripts/youtube_connect.py. Sign in with the Google account that owns your channel. This creates tokens/youtube_token.json.
  5. Restart run.bat. Your channels will show in the Upload step.
  6. Channel ID (optional, for the list below): YouTube Studio → Settings → Channel → Advanced settings → Channel ID. Or open your channel page — the ID starts with UC.

    Note: Adding a channel here only shows it in the Upload list. It does not enable uploading — that needs Google sign-in (steps above).
